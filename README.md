# Heaven for Death [BROWSER]
A playable version of Heaven for Death for browsers

You will be able to play on mobile devices such like Android and iPhone as soon as I have time to add controls, in the meanwhile you can play on anything that has a keyboard and runs a browser

----------------------------------------------------------

Controls:
- Movement: WASD or arrows, like always
- Interact with Z
- Cancel an action with X
- You can't jump
